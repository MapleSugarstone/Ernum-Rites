# Fonts shipped with Ernum Rites

All of these are licensed under the SIL Open Font License 1.1, which permits
bundling and redistribution with the game. They are shipped rather than named in
a stack because a font stack is a request: a machine without the faces it asks
for substitutes something else, and text drawn against one face does not hold on
another.

| File | Family | Source |
| --- | --- | --- |
| `source-sans-3-400.woff2`, `-600`, `-700` | Source Sans 3 | Adobe, SIL OFL 1.1 |
| `source-code-pro-400.woff2` | Source Code Pro | Adobe, SIL OFL 1.1 |
| `bodoni-moda-var.woff2` | Bodoni Moda (variable weight) | Owen Earl / indestructible type*, SIL OFL 1.1 |

Latin subsets, taken from the Fontsource packages of the same names.

The full licence text is at https://openfontlicense.org.
